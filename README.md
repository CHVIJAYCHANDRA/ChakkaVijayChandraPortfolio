# Chakka Vijay Chandra Portfolio

A static portfolio website showcasing projects, education, experience, and certifications.

## How to Run

### Method 1: Simple Browser Opening (Quick Start)
1. Navigate to the project folder
2. Double-click `index.html` to open it in your default web browser

### Method 2: Using Python HTTP Server (Recommended)
1. Open a terminal/command prompt in the project directory
2. Run one of the following commands:

**For Python 3:**
```bash
python -m http.server 8000
```

**For Python 2:**
```bash
python -m SimpleHTTPServer 8000
```

3. Open your browser and navigate to: `http://localhost:8000`

### Method 3: Using Node.js (if you have Node.js installed)
```bash
npx http-server -p 8000
```

### Method 4: Using VS Code Live Server Extension
1. Install the "Live Server" extension in VS Code
2. Right-click on `index.html`
3. Select "Open with Live Server"

## Project Structure

- `index.html` - Main HTML file
- `css/` - Stylesheet files
- `js/` - JavaScript files
- `images/` - Image assets
- `documents/` - PDFs and certificates
- `fonts/` - Font files

## Features

- Responsive design
- Portfolio sections: About, Skills, Education, Experience, Projects, Certifications
- Contact form
- Social media links

## Browser Compatibility

Works best on modern browsers (Chrome, Firefox, Edge, Safari).
